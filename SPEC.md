Create a BareScript MarkdownUp application to 3D-view a road grading plan model. The road grading plan model contains
information about the area topography, the start and end points of the road, the road path, and locations of special
engineering such as cut, fill, retaining wall, etc. A road model can contain one or more road plan options - the viewer
will allow the user to select the option. The application should compute a cost score for the project to compare plan
option costs - probably not dollars but something to understand comparative magnitude. The road plan models are
generated by the application's makefile plan target: `make plan FILE=<plan.png>`. The topo map image file (here
plan.png) must have the road start and end point clearly labeled. The "plan" make target launches claude code terminal
with detailed instructions on how to engineer a cost optimal road from start to end and generate a road plan model. You
must research road engineering and construction methods to create these instructions. The "plan" make target outputs
"<plan>.json", the road plan model. If there are multiple good options to choose from, the plan model may generate
multiple road plans. To view the road model, use `make run FILE=<plan.json>`.
